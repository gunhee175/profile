## 관심 분야

---

### 📊 데이터 시각화 (Data Visualization)

```
무선 신호 데이터, 보안 로그 등 복잡한 데이터를
직관적인 시각적 형태로 표현하는 것에 관심이 있습니다.

- CSI/BFI 무선 전파 데이터 시각화
- 보안 이벤트 로그 분석 시각화
- Python matplotlib, seaborn 활용
```

---

### 📡 전파 분석 (Radio Frequency Analysis)

```
WiFi 및 무선 통신 신호의 물리 계층 특성을 분석하는
연구에 깊은 관심을 가지고 있습니다.

- CSI(채널 상태 정보) 분석
- BFI(빔포밍 피드백 정보) 패턴 연구
- 802.11 표준 무선 통신 신호 처리
- WiFi-Sensing 기술 (비접촉 감지)
```

---

### 🦠 악성코드 분석 (Malware Analysis)

```
악성 소프트웨어의 동작 원리를 분석하고
대응 방안을 연구하는 분야에 관심이 있습니다.

- 정적 분석 (Static Analysis)
- 동적 분석 (Dynamic Analysis)
- 공급망 공격(Supply Chain Attack) 탐지
- 역공학(Reverse Engineering) 기법
```

---

### 🛸 차세대 표준 통신 기술 (Next-Gen Communication)

```
5G/6G 등 차세대 무선 통신 표준과
그에 따른 보안 이슈에 관심이 있습니다.

- IEEE 802.11be (WiFi 7) 표준
- 5G/6G 무선 통신 보안
- MIMO/빔포밍 기술
- 차세대 통신 환경에서의 프라이버시 위협
```
