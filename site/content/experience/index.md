## 주요 연구 활동 (시간순)

### 1. XZ 취약점 분석 탐구

```
분야   : 소프트웨어 취약점 분석 (CVE-2024-3094)
내용   : XZ Utils 백도어(Backdoor) 취약점 분석
         - 공급망 공격(Supply Chain Attack) 메커니즘 연구
         - 악성 코드 삽입 방식 및 탐지 기법 조사
         - 오픈소스 보안의 취약점과 시사점 분석
```

### 2. WiFi-Sensing 연구

```
분야   : 무선 전파 분석 / WiFi 감지 기술
내용   : WiFi 신호를 활용한 비접촉식 센싱 연구
         - CSI(Channel State Information) 데이터 수집 및 분석
         - BFI(Beamforming Feedback Information) 전파 패턴 분석
         - 실내 환경에서의 행동 감지 가능성 탐구
```

### 3. CSI / BFI 무선 전파 분석 (현재)

```
분야   : 무선 통신 신호 분석
내용   : IEEE 802.11 표준 기반 CSI/BFI 데이터 심층 분석
         - 전파 환경 모델링
         - 차세대 무선 통신 보안 연구
         - 데이터 시각화 기반 패턴 분석
```
